# ui-state-auditor

Use this Skill when a frontend review needs user-perspective checks for contradictory state signals, unclear action ownership, mixed object identity, transient-state leaks, misalignment, overlap, clipping, or responsive geometry failures.

## Install

```bash
npx skills add https://github.com/ght2330/ui-state-auditor
```

The main guide is [`SKILL.md`](SKILL.md). Read the inspection playbook and geometry checks when the review needs a repeatable evidence trail.
